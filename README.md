# Clube de Leitura D'Elas — App

Plataforma web responsiva para gestão e organização do Clube de Leitura D'Elas.

## Tecnologia
Supabase

## Passos para executar o código:

1. Instalar dependências

npm install

2. Iniciar o Supabase local

npx supabase start
